# Система поиска инсайтов

Методика берёт темы для контента и продаж из того, что люди сами набирают,
смотрят и обсуждают, вместо того чтобы угадывать. Три пласта данных: поисковые
подсказки, подсказки YouTube, живые обсуждения. Поверх них ложатся боли по
стадиям аудитории и карта возражений.

## Где лежат скрипты

Скрипты лежат в папке `scripts/` рядом с этим файлом. Ниже `SKILL_DIR` означает
путь к папке скилла: Claude Code показывает его при загрузке скилла как «Base
directory for this skill». Нужен только Python 3.9+, сторонних библиотек нет.

## Нужны три вводных

- **Ниша:** чем занимается пользователь
- **Аудитория:** кто его клиенты
- **Продукт:** что он продаёт

Если чего-то нет, спросите. Не додумывайте нишу за пользователя: от неё
зависят корни, а от корней весь сбор.

## Что где работает

| Блок | Инструмент | В облачной сессии |
|---|---|---|
| 1. Подсказки Google | `scripts/collect_suggest.py` | работает |
| 2. Подсказки YouTube | тот же скрипт | работает |
| 3. «Вопросы по теме» | браузер | нет |
| 4. Режим ИИ Google | браузер с логином в Google | нет |
| 5. Reddit | браузер | нет |
| Темы для постов | `scripts/topics.py` + модель | работает |
| 6. Сведение | модель | работает |

Блокам 1–2 браузер не нужен. Эндпоинт подсказок отвечает на обычный HTTP-запрос
без логина и капчи, это проверено из облачного контейнера. Скрипт делает за
секунды то, на что у браузерного агента уходят часы.

Блокам 3–5 нужен браузер, а режиму ИИ ещё и вход в Google: без него Google
показывает капчу «подозрительный трафик». Логиниться нужно в том браузере,
которым управляет агент, а не в личном Chrome. В эфемерной облачной сессии таких
блоков нет. Скажите об этом прямо и сделайте 1, 2 и 6. Не изображайте выдачу,
которую не видели.

Лёгкие браузерные агенты без входа в аккаунт сюда не годятся: режиму ИИ нужен
логин, а лента Reddit требует прокрутки с подгрузкой.

## Быстрый путь: темы для постов

Если пользователь просит темы для постов, начните с них. Полный разбор по
блокам 1–6 предложите вторым шагом.

1. Составьте корни, как в блоке 1, и соберите подсказки:

   ```bash
   python3 "$SKILL_DIR"/scripts/collect_suggest.py seeds.txt -o out/
   ```

2. Отранжируйте их:

   ```bash
   python3 "$SKILL_DIR"/scripts/topics.py seeds.txt out/
   ```

   Скрипт размечает каждую фразу сигналами (боль, недоверие, деньги, выбор,
   бизнес, свежее, как сделать), группирует по корню и главному сигналу и
   пишет `out/темы-кандидаты.md`. Сигналы считаются только по словам, которые
   дописали люди: пробные «стоит ли» и «правда ли» сборщика отрезаны, иначе
   недоверие получила бы каждая тема. Фразы без общего слова с корнями
   отбрасываются как ушедшие от темы.

3. Прочитайте `темы-кандидаты.md` и выдайте 10–15 тем. Начните со сквозных:
   окончание, которое дописывают к разным корням («не работает» к 17
   площадкам), даёт серию постов, по одному на площадку.

Каждая тема в списке:

- **Заголовок словами аудитории**, из реальной фразы. Не переводите его на язык
  маркетолога: человек узнаёт в заголовке свою мысль.
- **О чём пост**, одной строкой.
- **Почему сейчас**: сигнал и цифра из файла, например «цену спрашивают про 22
  площадки».
- **Структура**: боль и разочарование ложатся на «и, но, поэтому» (ABT);
  недоверие на историю с середины (in medias res) с разбором случая; «как
  сделать» на Pixar Story Spine; сравнение на «до и после».

Правила:

- Темы с пометкой «ученики» показывайте отдельно. Это люди, которые осваивают
  профессию, а не покупают услугу. В список для клиентов они не входят, если
  пользователь сам не учит.
- Не выдумывайте цифр: каждая цифра должна найтись в `темы-кандидаты.md` или
  `stats.json`.
- Читателю пишите на «вы». Если установлен скилл `stop-slop`, прогоните список
  через него; в русском тексте оставляйте тире, которых требует грамматика.
- Скажите, что блоки 3–5 не собраны, если это так: темы взяты только из
  подсказок.

### Актуальность

Один прогон даёт срез спроса, а не тренд. Чтобы увидеть, что набирает силу,
сохраните папку `out/` и через 2–4 недели запустите сбор снова:

```bash
python3 "$SKILL_DIR"/scripts/topics.py seeds.txt out-new/ --prev out/
```

Фразы, которых не было в прошлый раз, получают пометку «новое» и прибавку к
баллам. Учитывайте шум: два прогона в один день расходятся на 3% фраз, потому
что подсказки плавают. Тему стоит считать набирающей силу, только если в ней
несколько новых фраз и они пришли спустя время.

Без второго прогона «свежее» означает только явные приметы: текущий или
прошлый год в запросе, «новый», нейросети, алгоритмы.

## 1. Что набирают в поиске

Составьте 25–30 корневых фраз. Это семена для сбора, а не готовые запросы.
Возьмите их с пяти сторон:

- как тему называет сам пользователь
- как её называет клиент, который в ней не разбирается
- синонимы и сокращения, полные и аббревиатурой
- смежные проблемы, с которых человек начинает путь к продукту
- популярные инструменты и конкуренты ниши

Сохраните корни по одному в строке и запустите:

```bash
python3 "$SKILL_DIR"/scripts/collect_suggest.py seeds.txt -o out/
```

Скрипт добавляет к каждому корню 33 буквы алфавита и 11 вопросительных слов
(«как», «почему», «можно ли», «стоит ли», «что делать если» и другие), то есть
45 запросов на корень и источник. По умолчанию идёт 6 параллельных запросов;
при трёх отказах по лимиту скрипт останавливается, а не долбит эндпоинт.

Потом прочитайте `out/подсказки-поиск.txt` целиком: выкиньте то, что не по теме,
и сгруппируйте остальное. Скрипт режет только механический мусор, смысл решает
модель.

## 2. Что смотрят

Тот же запуск собирает подсказки YouTube. Цифры пересечения берите из
`out/stats.json`, а не из памяти: доля фраз, общих для обоих источников, и
сколько живёт только в одном.

Главный материал лежит в `out/только-видео.txt`. Разберите его на пять групп:

- страхи и сомнения: «почему опасно», «правда ли что», «чем грозит»
- проблемы, которые человек испытывает до знакомства с решением
- вопросы, которые стыдно задать публично
- запросы новичков: «что это», «с чего начать», «чем отличается»
- инструменты, которых нет в поисковых подсказках

**Подсказки YouTube сильно замусорены.** Скрипт чистит их в два слоя, а полные
данные кладёт в `out/сырые/`:

- обрывки слов на буквенные пробы, «копирайтинг ыры», отсекаются в обоих
  источниках (в проверке это 27% сырых подсказок YouTube и 5% у Google);
- из списка «только видео» дополнительно уходит форма «корень плюс одно
  слово», «маркетолог яблони», «таргет вк ноутбук». В прогоне на 28 корнях
  такой мусор составил 58% этого списка. Пересечение источников считается
  до этого шага, иначе сравнение было бы нечестным.

Остальной мусор вроде игр и эха запроса в другом падеже («зачем таргет
вкусняшки») вычищайте при чтении.

Следите и за тем, кто спрашивает. В YouTube заметная доля запросов идёт от
людей, которые хотят освоить профессию из ниши, а не купить услугу: «как стать
таргетологом», «сколько зарабатывает смм специалист». Отделяйте их от клиентов.

## 3. Что спрашивают прямо

В браузере откройте обычную выдачу Google по 10–12 главным запросам и соберите
блоки «Вопросы по теме» и «Другие также ищут».

Посчитайте повторяющиеся слова. Если в половине запросов стоят «реально»,
«правда ли», «развод», «стоит ли», значит, аудитория не доверяет нише, и это
придётся отрабатывать в каждом материале.

## 4. Боли и возражения

Режим ИИ Google открывается прямой ссылкой, запрос подставляется в неё целиком:

```
https://www.google.com/search?udm=50&q=ЗАПРОС
```

**Каждый срез задавайте в отдельной вкладке.** В одном чате тема первого
запроса прилипает и портит следующие ответы. Вкладки можно открывать по четыре.

Шесть срезов по 20 пунктов:

1. почему не покупают, что останавливает на самом деле
2. почему откладывают или срываются на полпути, живым языком форумов, и что
   стоит за каждой причиной
3. вопросы новичков, которые ещё не начали, разговорным языком
4. вопросы тех, кто пробовал и разочаровался: что именно не вышло
5. вопросы тех, у кого получается и кто хочет большего
6. формулировки реальных людей с площадкой и датой

Держите ответы раздельно по стадиям. Общий список даёт усреднённую банальщину,
а по стадиям выходят три разных набора болей.

### Правило о цитатах

Режим ИИ не копирует цитаты, он восстанавливает их по смыслу. Для языка
аудитории такие формулировки годятся. Выдавать их за настоящие слова людей
нельзя.

Каждую формулировку из среза 6, у которой нет проверяемого источника, пометьте
`[реконструкция]` и сохраните пометку в итоговом документе. Подлинной считайте
только цитату, которую вы открыли по ссылке и прочитали на месте.

## 5. Что обсуждают между собой

Подберите 8–10 сообществ Reddit по нише. Работает только обычный веб-интерфейс:

```
https://www.reddit.com/r/НАЗВАНИЕ/search/?q=ЗАПРОС&restrict_sr=1&sort=top&t=year
```

JSON-ручка отвечает 403, это проверено. `old.reddit` тоже не пускает без логина.

Прокрутите страницу 5–6 раз, иначе подгрузится семь постов вместо пятнадцати.
Ширина важнее глубины: 8–10 сообществ по 12–15 постов дают больше, чем сто
постов одного сообщества.

**Ранжируйте по числу комментариев, а не по лайкам.** Лайк значит «согласен»,
комментарий значит «болит, не могу молчать». Пост с 50 лайками и 200
комментариями ценнее поста с 2000 лайков и 12 комментариями.

Ответьте на три вопроса:

- какие темы собирают больше всего комментариев
- что из этого не встретилось ни в подсказках, ни в «Вопросах по теме»
- где отношение к теме расходится между сообществами

Reddit почти целиком англоязычный. Для русскоязычной аудитории добавьте
профильные русские форумы и комментарии на площадках ниши. Это дополнение
скилла, в исходной методике его нет.

## 6. Сведение

Три файла сырых данных уже лежат в `out/`. Четвёртым соберите
`банк-инсайтов.md` из двух разделов.

**Раздел 1. Банк тем**, три группы:

- **Высокая эмоция.** Живёт только в видео и обсуждениях: страхи, конфликты,
  разочарования. Конкуренции почти нет, виральность высокая.
- **Экспертные.** Люди спрашивают прямо. Строят доверие, виральности не дают.
- **Опережающие.** Их уже обсуждают, но почти никто о них не пишет.

Каждую тему формулируйте словами аудитории, а не языком маркетолога.

**Раздел 2. Карта возражений** по трём стадиям: не начал, пробовал и
разочаровался, уже получается. Для каждого возражения укажите, как оно звучит
словами клиента, что за ним стоит, на какой стадии возникает и чем закрывается.

Назовите самое частое возражение и самое сильное отдельно: это разные вещи.
Самым сильным часто оказывается не цена и не сложность, а инерция «мне и так
нормально». Тогда продающий текст начинается с проблемы, а решение идёт вторым.

В конце дайте список слов и оборотов, которыми говорит аудитория.

Пользователю пишите на «вы». Если установлен скилл `stop-slop`, прогоните
документ через него.

## Если сломалось

| Симптом | Причина |
|---|---|
| Скрипт остановился на лимите | Слишком много параллельных запросов. Уменьшите `--workers`. |
| Мало подсказок | Мало корней. 28 корней в проверке дали 4 617 фраз Google, три корня только 515. |
| Капча в блоках 3–4 | Агентский браузер не залогинен в Google. |
| Ответы в блоке 4 повторяются | Срезы заданы в одном чате. Нужна новая вкладка на каждый. |
| Reddit пустой | Агент полез в JSON или не прокрутил страницу. |

## Как применять результат

**Контент.** Основной материал лежит в группе «высокая эмоция»: этих тем нет в
поиске, и конкуренты их не видят. Заголовок берите дословно из формулировки
аудитории, человек узнаёт в нём свою мысль. Заходите через исходную проблему,
а не через продукт: человек ещё не ищет решение, он знает только, что у него
что-то не выходит.

**Продажи.** Карта возражений служит и сценарием звонка, и планом контента.
Новичок боится и не понимает, разочаровавшийся не верит после неудачи,
продвинутый спрашивает про масштаб. Одним текстом их не закрыть, нужны три.

## Проверено

Два прогона из облачного контейнера, 6–7 октября 2026:

| | 3 корня | 28 корней |
|---|---|---|
| Ниша | копирайтинг | маркетинг в отечественных соцсетях |
| Запросов на источник | 135 | 1 260 |
| Время сбора | 9–11 с | 95–105 с |
| Отказов по лимиту | 0 | 0 |
| Google, после чистки | 515 фраз | 4 617 фраз |
| YouTube, после чистки | 221 фраза | 2 039 фраз |
| Только видео, после чистки | 186 | 658 |
| Пересечение (Жаккар) | 5,0% | 7,8–7,9% |

Исходная методика говорит о пересечении «около 7%». На 28 корнях вышло 7,8%,
на трёх 5%. Подсказки немного плавают между запусками: на 28 корнях сырых фраз
YouTube было 2 605, 2 766 и 2 792 в трёх прогонах подряд.

Ещё одно утверждение методики не подтвердилось. Там сказано, что без
параметров `ie` и `oe` русский текст приходит битой кодировкой. В прямом
запросе ответ остался валидным UTF-8 и с ними, и без них. Скрипт всё равно их
передаёт, это ничего не стоит.
