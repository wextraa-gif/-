# audience-insights

Скилл для Claude Code, который находит темы для постов в том, что ваша
аудитория сама ищет в Google и YouTube.

Вы называете нишу, аудиторию и продукт. Скилл собирает тысячи поисковых
подсказок, отсеивает мусор и выдаёт 10–15 тем. У каждой темы есть заголовок
словами аудитории, цифра, которая объясняет, почему тема важна сейчас, и
подходящая структура поста. Дальше по желанию он собирает банк тем и карту
возражений по стадиям: не начал, пробовал и разочаровался, уже получается.

## Что он находит

- **Сквозные темы.** Одно и то же окончание люди дописывают к разным
  площадкам. В тестовой нише «маркетинг в соцсетях» слово «цена» нашлось у 23
  корневых фраз, «не работает» у 17. Из такой темы выходит серия постов, по
  одному на площадку.
- **Темы только из YouTube.** В тестовых прогонах подсказки Google и YouTube
  совпали лишь на 5–8%. Остальное в YouTube составляют страхи и вопросы,
  которые человек не набирает в обычном поиске.
- **Кто спрашивает.** Скилл отделяет клиентов от тех, кто сам осваивает
  профессию, чтобы они не смешивались в одном списке.

## Установка

Нужны Claude Code и Python 3.9 или новее. Сторонние библиотеки не нужны.

```bash
git clone https://github.com/wextraa-gif/-.git audience-insights-repo
mkdir -p ~/.claude/skills
cp -r audience-insights-repo/audience-insights ~/.claude/skills/
```

Перезапустите Claude Code. Скилл подхватится сам.

## Как запустить

Напишите в Claude Code:

```text
Дай темы для постов.
Ниша: [чем вы занимаетесь]
Аудитория: [кто ваши клиенты]
Продукт: [что вы продаёте]
```

Сбор подсказок занимает 1–2 минуты и работает в любой сессии, в том числе в
веб-версии Claude Code. Для блоков с «Вопросами по теме», режимом ИИ Google и
Reddit нужен браузер, в котором вы вошли в Google. Без него скилл честно
скажет, что эти блоки не собраны.

## Актуальность

Один прогон показывает, о чём спрашивают сейчас. Чтобы увидеть, что набирает
силу, сохраните папку с результатами и через 2–4 недели попросите повторить
сбор со сравнением. Новые запросы будут помечены. Два прогона в один день
расходятся примерно на 3% фраз, поэтому трендом стоит считать только то, что
прибавило заметно больше.

## Ограничения

- Подсказки показывают, что ищут, но не сколько раз. Частоты здесь нет.
- Цитаты из режима ИИ Google модель восстанавливает по смыслу. Скилл помечает
  их `[реконструкция]` и не выдаёт за слова реальных людей.
- Reddit почти целиком англоязычный. Для русской аудитории скилл предлагает
  русские форумы и комментарии на площадках ниши.
