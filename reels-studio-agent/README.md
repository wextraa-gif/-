# Reels Studio — агент для монтажа Reels и VK Клипов

Агент для Claude Code. Монтирует вертикальные ролики из «говорящей головы» или записи
выступления в **вашем** фирменном стиле. Перед первой работой проводит онбординг
и без него монтировать не начинает.

## Онбординг: что агент спросит

1. **Шрифт субтитров.** Покажет превью 16 бесплатных шрифтов с кириллицей (лицензия
   SIL OFL, можно в коммерции) и даст выбрать.
2. **Цвет акцентных слов** в субтитрах.
3. **Примеры анимаций.** Пришлите 2–5 картинок или ссылок на Pinterest. Агент выведет
   из них стиль плашек, иконок и движения: материал, цвета, кромку, глубину, способ
   появления. Не копируя сами изображения.
4. **Примеры обложек.** Тоже 2–5 картинок или ссылок. Агент подберёт раскладку
   (фото сквозь буквы, буквы за человеком, заголовок на плашке), шрифт, цвета, фон
   и журнальные детали.
5. **Лист стиля.** Субтитр, анимации и обложка на одном листе. Агент вносит правки,
   пока вам не понравится. Только после одобрения начинает монтировать.

## Что агент делает с роликом

- Распознаёт речь двумя моделями Whisper и вычитывает субтитры.
- Вырезает паузы, оставляя небольшой запас, похожий на естественную паузу между словами.
  Убирает «э-э» и «ммм».
- Кадрирует под 9:16 по лицу, делает плавные зумы на акцентных словах.
- Ставит субтитры по 2–3 слова с цветным акцентным словом.
- Добавляет 2–5 анимированных плашек, иконок и чек-листов в вашем стиле.
- Делает обложку с заголовком из 1–2 слов и ставит её первым кадром,
  а также отдаёт её отдельным файлом.
- Выдаёт файл 1080×1920, 30 кадров в секунду, громкость −14 LUFS — для Reels и VK Клипов.

## Установка

Скопируйте папку `.claude` из этой директории в корень своего проекта
(или в `~/.claude`, чтобы агент был доступен во всех проектах):

```bash
cp -r reels-studio-agent/.claude/. /путь/к/проекту/.claude/
```

Зависимости (ffmpeg должен быть установлен в системе):

```bash
pip install -r .claude/skills/reels-studio/requirements.txt
```

## Запуск

- Агент — основной собеседник: `claude --agent reels-studio`
- Или в любой сессии Claude Code: команда `/reels-studio` либо просьба
  «смонтируй рилс из этого видео».

Агент сам проверит, пройден ли онбординг. Профиль стиля сохраняется
в `.claude/skills/reels-studio/brand/`. Закоммитьте его, чтобы стиль не пропал.
Сменить стиль: попросите агента. Начать заново: `brand.py reset`.

## Состав

```
.claude/
  agents/reels-studio.md            — агент: онбординг → монтаж
  skills/reels-studio/
    SKILL.md                        — инструкция: онбординг, порядок монтажа, стиль
    scripts/brand.py                — профиль стиля, каталог шрифтов, референсы, лист стиля
    scripts/transcribe.py, cut.py   — распознавание речи, склейка с живыми паузами
    scripts/captions.py             — субтитры
    scripts/fx.py                   — анимации (стиль из профиля)
    scripts/cover.py, poster.py     — обложки (стиль из профиля)
    scripts/render.py, make_clip.py — сборка ролика
    fonts/                          — Inter (интерфейс) + шрифты, выбранные при онбординге
    models/                         — детектор лиц YuNet (MIT)
    brand/                          — профиль стиля и референсы пользователя
```
