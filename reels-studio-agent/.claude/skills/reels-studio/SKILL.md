# Reels Studio

Монтаж вертикальных роликов в стиле, который задаёт сам пользователь. Всё оформление
живёт в профиле `brand/brand.json`; скрипты из `scripts/` берут шрифт, цвета, вид
анимаций и обложек оттуда. **Пока онбординг не пройден, монтаж не запускается** —
скрипты сами откажутся работать.

К пользователю — на «вы», по-русски, коротко.

## Подготовка (один раз за сессию)

```bash
S=.claude/skills/reels-studio/scripts
python3 -c "import faster_whisper, rembg, fontTools, cv2; assert hasattr(cv2, 'FaceDetectorYN')" 2>/dev/null \
  || pip install -q --break-system-packages -r .claude/skills/reels-studio/requirements.txt
python3 $S/brand.py status
```

Если статус `ready` — онбординг пройден, сразу переходите к «Порядку монтажа».
Иначе — сначала онбординг, по шагам ниже, даже если пользователь уже прислал видео
(видео пригодится для превью стиля).

## Онбординг

Задавайте вопросы по одному шагу, не вываливайте всё сразу. Если вы работаете
отдельным агентом без доступа к пользователю — не придумывайте ответы за него:
верните вопросы основному диалогу и остановитесь.

### Шаг 1. Шрифт субтитров

1. `python3 $S/brand.py fonts-preview` → отправить пользователю `brand/fonts_preview.png`
   (SendUserFile): 16 бесплатных шрифтов с кириллицей, лицензия OFL — можно в коммерции.
2. Спросить через AskUserQuestion «Какой шрифт для субтитров?» — 4 варианта, которые
   лучше подходят под тематику, о которой пользователь уже рассказал (по умолчанию:
   Oswald, Montserrat, Golos Text, Unbounded); в «Другое» он может вписать номер или
   название из превью. Полный список — `python3 $S/brand.py fonts`.
3. `python3 $S/brand.py set-font <ключ> --weight 600` (узким и плакатным — 600–700,
   широким — 600; у PT Sans Narrow и Russo One одно начертание).

### Шаг 2. Цвет акцентных слов

AskUserQuestion «Какой цвет для акцентных слов?»: лайм `#C8FF2E`, жёлтый `#FFD60A`,
коралловый `#FF5A5F`, голубой `#3DD6FF`; в «Другое» — любой HEX или название цвета
(переведите в HEX сами). → `python3 $S/brand.py set-accent "#RRGGBB"`.
Тот же цвет по умолчанию становится акцентом анимаций и обложек.

### Шаг 3. Стиль анимаций — референсы

Попросите прислать 2–5 примеров анимаций/графики, которые нравятся (картинки или
ссылки на пины Pinterest; скриншоты из видео тоже подойдут). Сохраните каждый:
`python3 $S/brand.py add-ref fx <файл или ссылка>`. Если Pinterest не отдал картинку по
ссылке — попросите прислать её файлом.

Посмотрите референсы (Read) и выведите **стиль, а не копию**: материалы, цвета,
глубину, форму, характер движения. Не переносите конкретные изображения, тексты,
логотипы и композиции. Переведите увиденное в параметры:

| Что видно на референсах | Параметр `fx` |
|---|---|
| матовое тёмное стекло / светлое стекло / сплошные плашки / только контур | `surface`: `glass-dark` / `glass-light` / `solid` / `outline` |
| цвет заливки и её плотность | `fill` (HEX), `fill_opacity` 0–1 (для solid — непрозрачность) |
| насколько размыт и затемнён фон под стеклом | `blur` 6–24, `darken` 0.3–0.8 |
| скругление углов | `radius` 0–60 (px при 1080×1920) |
| кромка: цвет, толщина, яркость | `rim_color`, `rim_width` 0–6, `rim_opacity` |
| тени и глубина | `shadow` 0–0.8, `tilt` 0–20 (3D-наклон), `float` (парение) |
| блик по стеклу | `sheen` true/false |
| как появляются элементы | `entrance`: `swing` (разворот в 3D) / `pop` (пружинка) / `slide` (выезд) / `fade` |
| иконки: металл / плоские / контурные | `icon_finish`: `chrome` / `flat` / `outline`, `icon_color` |
| цвета текста | `text_color`, `muted_color` (подписи), `accent` (если не как у титров) |
| шрифт интерфейса | `ui_font` — `inter` или ключ из каталога шрифтов |

Запишите: `python3 $S/brand.py set fx '{"surface":"glass-dark", ... , "notes":"что взято из референсов"}'`.
В `notes` 1–2 фразы: какие черты стиля взяты и что сознательно не копировалось.

### Шаг 4. Стиль обложек — референсы

Так же попросите 2–5 примеров обложек → `python3 $S/brand.py add-ref cover <файл/ссылка>`.
Выведите стиль и переведите в параметры:

| Что видно | Параметр `cover` |
|---|---|
| фото видно сквозь огромные буквы | `layout: "knockout"`, `title_fill: "photo"` |
| сплошные буквы, человек стоит перед ними | `layout: "text-behind"`, `title_fill: "solid"`, `person: "front"` |
| заголовок на плашке поверх кадра | `layout: "glass"` (в стиле субтитров) |
| человек между словами (перед первым, за вторым) | `person: "sandwich"` |
| фон: бумага / однотонный / размытое фото | `bg`: `paper` / `solid` / `photo-blur`, `bg_color` |
| цвет мелкого текста и букв | `ink`, `title_color` |
| шрифт заголовка: узкий плакатный / широкий / антиква | `title_font` (ключ каталога), `title_weight` 600–900 |
| насколько буквы вытянуты по вертикали | `stretch` 1.0–2.8 |
| регистр | `title_case`: `upper` / `as-is` |
| второе слово перед человеком | `front_word`: `graphite` / `accent` / `solid` |
| зерно бумаги, «вырезанные» буквы с тенью | `grain`, `paper_cut` |
| журнальные детали | `decor`: `kicker`, `year`, `note`, `issue`, `side`, `stamp` — true/false |

`python3 $S/brand.py set cover '{...,"notes":"..."}'`

### Шаг 5. Лист стиля и одобрение

`python3 $S/brand.py board [--frame кадр.jpg]` — лист из трёх превью: субтитр, анимации,
обложка. Если пользователь уже прислал видео, возьмите кадр с человеком
(`ffmpeg -ss 5 -i in.mp4 -frames:v 1 frame.jpg`) — так обложка покажет вырезанного
человека. Отправьте лист пользователю и спросите, всё ли нравится.
Правки → `brand.py set ...` → новый лист. Когда пользователь доволен:
`python3 $S/brand.py approve`.

Сохраните профиль в репозиторий (папка `brand/` и шрифты `fonts/sub-*`, `fonts/title-*`,
`fonts/ui-*`): облачная сессия временная, без коммита стиль пропадёт. Сменить стиль
позже — `brand.py set ...` и снова `approve`; начать заново — `brand.py reset`.

## Порядок монтажа

Модели Whisper скачиваются при первом запуске (medium ≈ 1,5 ГБ, large-v3-turbo ≈ 1,6 ГБ),
модель вырезания человека — 176 МБ. Исходники с iPhone (HEVC, 4K, 60 к/с, поворот)
читаются как есть. Видео кладите в отдельную папку вне репозитория; служебные файлы
появятся рядом в `.<имя>_montage/`. Модель видит только кадры и не слышит звук, поэтому
паузы режутся по таймкодам слов и громкости.

1. **Распознать речь** — `python3 $S/transcribe.py in.mp4 --alt large-v3-turbo`.
   Таймкоды слов — от medium (не теряет фразы); `transcript_large-v3-turbo.txt` — для
   сверки (лучше слышит слова в шуме, но может пропускать реплики).
2. **Выбрать фрагменты** (для длинного выступления): предложить 2–4 момента с таймкодами
   и цитатами, 15–60 секунд, и дождаться выбора. Несколько кусков: `--ranges 63.2-81.5,95-118`.
3. **Склеить и собрать титры без рендера**:
   `python3 $S/make_clip.py in.mp4 out.mp4 [--ranges ...] --stop-after-captions`
4. **Вычитать `captions.json`** — обязательно:
   - исправить ошибки распознавания, сверяясь со вторым текстом и смыслом; сомнительное
     не выдумывать — оставить лучший вариант и назвать в отчёте; галлюцинации удалить;
   - числа цифрами; акценты (`"accent"` — номер слова или `null`) на ключевых словах,
     примерно на каждом втором-третьем титре; предлоги и «это» — никогда;
   - `start`/`end` не менять, больше 3 слов в титр не склеивать;
   - зумы (`"zoom": true`) — 2–4 на ролик, на сильных акцентах, когда в кадре говорящий.
5. **Анимации** — 2–5 элементов в `.<имя>_montage/fx.json` (раздел «Анимации»).
6. **Обложка** — кадр, заголовок и подписи выбираете сами (раздел «Обложка»).
7. **Собрать**: `python3 $S/make_clip.py in.mp4 out.mp4 --skip-to-render`
8. **Проверить**: раскадровку `out.sheet.jpg`, 2–3 кадра с титрами
   (`ffmpeg -v error -ss 5 -i out.mp4 -frames:v 1 -vf scale=540:-2 frame.png`), паузы
   (`ffmpeg -i out.mp4 -af silencedetect=n=-40dB:d=0.12 -f null - 2>&1 | grep silence_duration`,
   норма 0,2–0,6 с), каждую анимацию через ~1 с после старта (+0,1 с обложки): не
   закрывает лицо и титры, текст читается. Ошибки — исправить и пересобрать самим.
9. **Отдать** ролик и `cover.jpg` (SendUserFile) со сводкой: длительность до/после,
   склейки, зумы, что поправлено в тексте, запасные заголовки обложки.

Музыкальную подложку не добавлять — только голос.

## Паузы

`cut.py` режет по границам слов, уточнённым по громкости. Паузы короче `--min-pause`
(0,45 с) не трогаются; на месте длинной остаётся «воздух»: `--pause` 0.30 внутри мысли,
`--sentence-pause` 0.45 после конца предложения (40% перед фразой, 60% после).
«Э-э», «ммм» вырезаются; на стыках звук сводится за 15 мс. «Рвано» — `--pause 0.4`,
«затянуто» — `--pause 0.22 --min-pause 0.35`.

## Кадр и зумы

`--reframe auto`: горизонтальное видео кадрируется 9:16 по лицу (детектор YuNet),
лица нет — кадр на размытом фоне; вертикальное только масштабируется. Зум — плавный
наезд ×1,1 на титрах с `"zoom": true` (0,35 с наезд, 0,7 с отъезд), якорь — лицо в этот
момент. `--zoom-depth`, `--no-zoom`.

## Анимации

Рисует `scripts/fx.py` в стиле из профиля (`brand.json → fx`). Время — `"cap": номер титра`
или `"t"` по шкале captions.json.

| Тип | Когда | Пример |
|---|---|---|
| `card` | цифра, результат, «уведомление» | `{"type":"card","cap":6,"title":"Удержание","value":"+120%","icon":"arrow_up","accent":true}` |
| `pill` | короткий тезис 1–3 слова | `{"type":"pill","cap":12,"text":"Без воды","icon":"check"}` |
| `list` | перечисление | `{"type":"list","cap":15,"title":"Чек-лист","items":["Паузы","Титры"],"step":1.2}` |
| `icon` | образ без текста | `{"type":"icon","cap":3,"icon":"cursor","size":180}`, `"glass":true` — в плашке |

Числа в `value` растут от нуля (`"countup": false`). Иконки: cursor, check, arrow_up,
star, bolt, heart, play, plus, chat, code, braces, percent, `"text:АБВ"`. Поля: `dur`,
`pos` (left/right/low-left/low-right/top-left/top-right/center) или `x`,`y`; `scale`.
Правила: 2–5 на ролик, по одному на экране, только где добавляют смысл; текст короче
титра; не закрывать лицо и титры. Проверка одного момента:
`python3 $S/fx.py still in.mp4 --t 7.5 --from out.mp4 -o still.png`. Без анимаций — `--no-fx`.

## Обложка

Первый кадр ролика (0,1 с, `--cover-hold`) и отдельный `cover.jpg` для загрузки.
Вид — из профиля (`brand.json → cover`): постер с огромным заголовком из 1–2 слов
(`knockout` / `text-behind`) или заголовок на плашке (`glass`).

1. `python3 $S/cover.py candidates in.mp4` → посмотреть `cover_candidates.jpg`, выбрать
   кадр: человек целиком или по пояс, резкий, рядом никого.
2. Заголовок — 1–2 слова, суть ролика. `*звёздочками*` отметьте **первое** слово — оно
   будет в цвете акцента; второе, перед человеком, получит контрастную заливку.
3. ```bash
   python3 $S/cover.py make in.mp4 --t 12.0 --title "*Свой* чек" --kicker "Рубрика" \
     --year 2026 --note "Крючок из ролика|в две строки" --issue "Вып. 01" --side "тема" --stamp АБ
   ```
   Детали, выключенные в профиле (`decor`), не рисуются. Своя картинка по теме вместо
   кадра — `--image photo.jpg`; без вырезания человека — `--no-pop`.
4. Проверить `cover.jpg`: оба слова читаются, человек вырезан чисто, не закрывает
   нижний текст. В отчёте — 1–2 запасных заголовка.

## Субтитры

Шрифт, цвет, акцент, регистр, подложка — из профиля (`brand.json → subtitles`):
`plate` — `glass-dark` (матовое тёмное стекло), `glass-light`, `solid` (плашка
`plate_color` с непрозрачностью `plate_opacity`), `none` (обводка и тень). 2–3 слова
на экране, без висячих предлогов; центр строки на 1250 px — выше интерфейса Reels.
Поменять: `brand.py set subtitles '{"plate":"solid","plate_color":"#111111","case":"upper"}'`.

## Выход

H.264 High, 1080×1920, 30 к/с, AAC 192 кбит/с, −14 LUFS, `+faststart` — для Reels и VK Клипов.
